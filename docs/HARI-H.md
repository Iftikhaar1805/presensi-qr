# Daftar periksa hari H

## H-3 sampai H-1
- [ ] Aplikasi sudah di Vercel dan dibuka dari 2 HP berbeda (lihat DEPLOY.md bagian 4).
- [ ] Logo sekolah terunggah, password admin sudah diganti.
- [ ] Kartu kelas DEMO dicetak (10 kartu: 3 contoh dan 7 anggota tim), digunting, dilaminating. Coba pindai satu hasil cetak.
- [ ] Cadangan diunduh dan disimpan di laptop dan di HP.
- [ ] Jam masuk di Pengaturan disesuaikan dengan jam acara, atau siapkan tombol **Siapkan latihan sekarang**.
- [ ] Laptop terisi penuh, ada charger, ada kabel HDMI ke proyektor. HP cadangan dengan kuota.
- [ ] Mode lokal siap di laptop (`npm start`, buka `http://localhost:3000`) bila internet sekolah lambat.

## Pagi hari H
- [ ] Buka aplikasi sekali supaya database aktif.
- [ ] Pengaturan, **Siapkan latihan sekarang**.
- [ ] Papan kehadiran tampil di layar proyektor.
- [ ] Tes cepat: satu HP ambil kelas DEMO, pindai satu kartu, akhiri pelajaran.

## Saat acara
Ikuti `docs/DEMO.md` (urutan demo) dan `docs/materi-pkm/` (slide, panduan guru, instrumen evaluasi).

## Setelah acara
- [ ] Unduh cadangan terakhir.
- [ ] Unduh rekap bulanan dan rekap per pelajaran sebagai dokumentasi laporan PKM.
- [ ] Pengaturan, **Kembalikan data contoh** bila aplikasi akan dipakai ulang.
